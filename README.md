En este taller de  Estructura de datos se nos solicito un programa para ver la atención de diferentes personas para el hospital Marmaja. Para compilar este código en codespace debe ser a través de escribir en la terminal en la dirección donde se ubique el código el siguiente comando "g++ main.cpp NodoP.cpp Paciente.cpp Servicios.cpp -o main.exe" donde el "main.exe" del final corresponde al nombre del ejecutable, por lo tanto se puede cambiar. Para ejecutar el código es a través de escribir en la dirección el comando "./main.exe" o el nombre del ejecutable colocado.
